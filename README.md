# ooolzhas/tap

Homebrew formulae for [AnnotateKit](https://annotatekit.com).

```sh
brew install ooolzhas/tap/annotate
```

| Formula | What it is |
|---|---|
| `annotate` | The AnnotateKit CLI: delivers visual feedback from your running iOS app to coding agents (MCP server, watcher, headless runner). Source: [ooolzhas/annotatekit](https://github.com/ooolzhas/annotatekit) |

Each formula installs the checksum-verified universal macOS binary from the matching GitHub Release.
